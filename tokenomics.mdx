---
title: "Token & Incentive Framework"
description: "No token in V1 — a narrative-consistent framework for later"
---

No token is issued in V1 — only off-chain points and badges. Reason: before the product proves that anyone will pay for or rely on the score, a token adds only regulatory burden and farm-and-dump false growth.

If a token is introduced later, its design will follow the same Seed → Grow → Root → Network narrative:

- **Seed:** identity soulbound credentials — non-transferable, the individual's starting point in the network.
- **Grow:** early points evolve toward compute/data contribution incentives, rewarding quality data sources and feedback providers.
- **Root:** validator staking — introduced only when the validator set genuinely needs economic incentives to stay honest.
- **Network:** governance and ecosystem-access tokens for downstream parties who actually pay to use reputation data (lending protocols, merchants, institutions).

Whether and when to issue a token depends on real validation data from Phases 1–2. This whitepaper constitutes no commitment to any token issuance and no offer of securities.
