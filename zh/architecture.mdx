## 3.1 数据索引层

使用 Covalent / GoldRush、Moralis、Alchemy、The Graph、Dune Analytics 等现成基础设施，跨链抓取地址级别的公开链上数据（余额、交易、协议交互、NFT、质押与借贷记录）。V1 优先覆盖以太坊、Base、Solana 等交互密度最高的几条链，不自建索引器，降低前期工程与运维成本。

## 3.2 打分引擎：规则 + 轻量机器学习

**透明加权规则层：** 钱包年龄、交易广度与深度、协议多样性、质押与流动性历史、资产净值分布——用户能看懂自己为什么是这个分数，避免黑箱争议。

**轻量机器学习层：** 用 XGBoost / LightGBM 一类小规模模型做异常检测，识别刷分、女巫攻击、批量小号等规则打分容易被绕过的行为。训练与推理都不需要 GPU，一台普通云服务器即可运行——这是真正体现"AI"价值、而不是简单公式能替代的部分。

## 3.3 可选的 LLM 解读层

通过 API 调用现成大语言模型（而非自建、自训练模型），把打分结果转成一段人话解读，例如"你是一个长期活跃的 DeFi 参与者，偏好稳健借贷，很少参与投机性代币"。按调用量付费，边际成本低，可随时切换至更低成本的开源模型，不构成长期成本负担。

## 3.4 链上凭证与验证节点：诚实的信任假设

Ring 以灵魂绑定凭证（soulbound token / verifiable credential）形式发放，写入用户地址，不可转让、不可买卖。

V1 阶段由少量、身份公开、承担声誉责任的签名者（现阶段即团队本身，未来可引入 1-2 个可信合作方）共同签署打分结果并上链，明确告知用户当前的信任假设是什么，不假装"完全去中心化"。路线图上再逐步扩大到有质押要求的验证者网络。这里刻意不采用"人人都能跑节点"的模式——原因见[附录 A](/zh/appendix-a)。

## 3.5 成本结构（V1 预估，尽量把烧钱环节压到最低）

整体 V1 月度运营成本可控制在几百美元量级，不需要外部融资也能先跑起来、验证核心假设。

| 模块 | 技术选型 | 成本量级 |
|---|---|---|
| 链上数据索引 | Covalent / Moralis / Alchemy / The Graph 现成 API | 多为按量计费，前期免费额度可覆盖 MVP |
| 打分引擎训练与推理 | XGBoost / LightGBM，云服务器运行 | 每月数十至数百美元 |
| LLM 解读层 | 按调用付费的第三方 API，可选开源模型 | 按用量计费，边际成本低 |
| 链上凭证发放 | 部署在 Base / Arbitrum 等低 Gas L2 | 单次发放几分至几毛美元 |
| 验证签名 | V1 由团队自持签名，暂无额外成本 | 0 |
