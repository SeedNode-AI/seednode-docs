---
title: "代币与激励框架"
description: "V1 不发币——但未来的设计框架先定好"
---

V1 阶段不发行任何代币，仅使用链下积分与徽章。原因：产品尚未验证"分数是否真的有人愿意为之付费或采信"之前，代币只会带来不必要的监管负担与"刷分套现"式的虚假繁荣。

未来若引入代币，设计框架将沿用 Seed → Grow → Root → Network 四阶段叙事，而不是另起炉灶：

- **Seed 阶段：** 身份类灵魂绑定凭证，不可转让，代表个体在网络中的起点。
- **Grow 阶段：** 早期积分体系可能向计算 / 数据贡献激励过渡，用于奖励优质数据源或反馈提供者。
- **Root 阶段：** 验证者质押代币，只有当验证者网络真正扩大到需要经济激励维护诚实性时才会引入。
- **Network 阶段：** 治理与生态准入代币，面向真正开始付费使用声誉数据的下游合作方（借贷协议、商户、机构）。

是否发币、何时发币，取决于 Phase 1 与 Phase 2 的真实数据验证结果，本白皮书不构成任何代币发行的承诺或招股行为。
